# WPT 기반 다중 AGV Opportunity Charging Scheduling 시뮬레이션 보고서

## 1. Simulation Model
Python 3.11, SimPy(의존성 및 DES 환경 객체), NumPy/pandas 기반 이산사건형 AGV 작업-충전 시뮬레이션입니다. 작업은 Poisson arrival, FCFS + first-available AGV로 배정했으며, 충전전략 외 난수는 common random numbers로 공유했습니다.

## 2. Assumptions
- WPT 효율변동은 50 W prototype 절대효율을 kW급 효율로 직접 외삽한 것이 아니라, complete matching 79.96% 대비 상대 민감도를 산업 기준효율 90%에 곱한 synthetic scenario model입니다.
- Picking–Staging 거리는 Base Case에서 모두 동일하므로 E_next feature는 낮은 분산/비정보적일 수 있습니다.
- 작업지연은 `actual completion time - earliest physically possible completion time`으로 정의했습니다.

## 3. Base Case

- C1: throughput 74.88 ± 1.61 tasks/h, completion 99.77 ± 0.15%, delay 2.40 ± 1.59 min, stoppage 0.00 ± 0.00.
- C2: throughput 74.90 ± 1.63 tasks/h, completion 99.81 ± 0.11%, delay 0.20 ± 0.04 min, stoppage 0.00 ± 0.00.
- C3: throughput 74.90 ± 1.63 tasks/h, completion 99.81 ± 0.11%, delay 0.20 ± 0.04 min, stoppage 0.00 ± 0.00.
- C4: throughput 74.90 ± 1.63 tasks/h, completion 99.81 ± 0.11%, delay 0.20 ± 0.04 min, stoppage 0.00 ± 0.00.

## 5. C1~C4 definition
C1 threshold full charging, C2 always opportunity, C3 low-SOC priority, C4 normalized priority score(1-SOC, E_next, T_idle, eta, delay penalty)를 구현했습니다. C4도 SOC 안전규칙에 따라 critical SOC 이하는 mandatory charging 후보로 처리했습니다.

## 13. Limitations
실제 docking error 분포와 kW급 WPT 효율 실측분포가 없으므로 효율 state 확률은 synthetic assumption입니다. Pad 위치효과는 staging/picking 균형 배치 규칙으로 단순화했습니다.

## 14. Conclusions
Opportunity charging은 유휴시간이 충분하고 WPT가 과잉도 부족도 아닌 영역에서 threshold charging 대비 SOC 안정성과 지연 감소를 제공하는지 평가할 수 있었습니다. C4의 추가 이점은 raw/paired comparison에서 C2/C3 대비 실제 차이로 판단해야 하며, C4가 항상 최고라고 가정하지 않았습니다.

## 15. Recommended next experiments
- 실제 AGV 전력/주행거리 계측값으로 e_dist/P_aux 재보정
- 실제 docking error 로그 기반 효율 state 분포 추정
- heterogeneous picking distance와 pad 위치 모델 확장
- C4 feature ablation 및 calibration seed 전용 weight sensitivity 확장
